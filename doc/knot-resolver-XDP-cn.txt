═══════════════════════════════════════════════════════════════════════════════════════
                    为什么两个 XDP 程序是互斥的
═══════════════════════════════════════════════════════════════════════════════════════

    ┌─────────────────────────────────────────────────────────────────────────────────┐
    │  原因 1：XDP_REDIRECT 绕过                                                     │
    │  ───────────────────────────────────────────────────────────────────────────── │
    │  xdp_dns_denylist 使用 XDP_REDIRECT，将数据包直接发送到 socket，               │
    │  绕过同一接口上所有后续的 XDP 程序。                                            │
    │                                                                                 │
    │  结果：当 xdp_dns_denylist 运行时，dns_fw 接收不到任何数据包。                 │
    └─────────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────────────────────┐
    │  原因 2：通配符 vs. 精确匹配                                                    │
    │  ───────────────────────────────────────────────────────────────────────────── │
    │  xdp_dns_denylist：✅ 支持通配符域名（如 *.example.com）                        │
    │  dns_fw：          ❌ 仅支持完全限定域名（精确匹配）                            │
    │                                                                                 │
    │  结果：xdp_dns_denylist 功能更强，所以在 XDP=off 时使用。                       │
    │        当需要 XDP 加速时使用 dns_fw（但失去通配符支持）。                       │
    └─────────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────────────────────┐
    │  性能与功能权衡                                                                 │
    │  ───────────────────────────────────────────────────────────────────────────── │
    │                                                                                 │
    │  XDP 已禁用：                                                                    │
    │  ├── xdp_dns_denylist（支持通配符）                                             │
    │  └── knot-resolver 处理所有过滤（最慢但功能最强）                                │
    │                                                                                 │
    │  XDP 已启用：                                                                    │
    │  ├── dns_fw 处理 DNSBL（快速内核绕过）                                           │
    │  ├── ⚠️  仅支持精确域名匹配（不支持通配符）                                     │
    │  └── knot-resolver 处理最小化解析（最快）                                        │
    │                                                                                 │
    │  适合 XDP 已启用的场景：                                                         │
    │  - 高流量环境（10,000+ QPS）                                                    │
    │  - 仅包含精确域名的 DNSBL 列表                                                   │
    │  - 不需要通配符域名支持                                                          │
    │                                                                                 │
    │  适合 XDP 已禁用的场景：                                                         │
    │  - 中等流量（< 10,000 QPS）                                                     │
    │  - 需要通配符域名支持                                                            │
    │  - 更复杂的过滤规则                                                              │
